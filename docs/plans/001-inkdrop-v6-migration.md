# Inkdrop v6 対応計画

## 目的

narrow-tag を Inkdrop v6 に対応させ、タグの検索・選択によるノートの絞り込みと既存のキーボード操作を維持する。

## 参考資料

- Inkdrop ノート `note:8A61hl_h`「🚀 Inkdrop v6 対応」
- [公式移行ガイド](https://github.com/inkdropapp/api-docs/blob/main/src/app/appendix/plugin-migration-from-v5-to-v6/page.mdx)
- 対応済みの隣接プロジェクト `narrow-book`、`narrow-note`

## 調査結果

- 作業開始時点の未コミット差分はない。
- `package.json` の `engines.inkdrop` は `^5.x` のため更新が必要。
- v6 では LESS が廃止されている。現在のスタイルは通常の CSS 構文のため、拡張子を変更できる。
- `semantic-ui-react` の `Dropdown` を使用している。対応済みの `narrow-book` の計画には、v6 実行時の `ReactDOM.findDOMNode` エラーを理由に独自 UI に置換した記録がある。本プラグインも同様の方式で置換する。
- CodeMirror、`inkdrop.window.on()`、ローカル DB、`.mde-preview` は使用しておらず、ノートに記載されたそれらの移行は不要。
- グローバルの `inkdrop` は公式移行ガイド上、現時点では後方互換で利用可能。既存コードと隣接プロジェクトに合わせ、今回の移行では維持する。
- `inkdrop.components`、`inkdrop.layouts`、`useModal`、ストアからのタグ取得、コマンド実行、`.editor` 参照は v6 上で動作を確認する。

## 対応内容

- [x] `package.json` の `engines.inkdrop` を `^6.x` に変更する。
- [x] `styles/narrow-tag.less` を `styles/narrow-tag.css` に変更する。
- [x] `Dropdown` を入力欄と候補一覧からなる独自 UI に置換する。
- [x] タグ名検索、クリックと Enter による選択、上下キーと Ctrl-n / Ctrl-p による候補移動、Ctrl-w による検索クリア、Escape による終了を実装する。
- [x] ダイアログの位置・候補一覧の高さ・選択候補の表示を調整する。
- [x] `semantic-ui-react` 依存を削除し、ロックファイルを同期する。
- [x] README に Inkdrop v6 向けであることを記載する。

## 維持する動作

- `narrow-tag:open` で全タグの候補を表示する。
- タグ選択後、全ノート表示・検索解除・タグ絞り込みの既存の流れを維持する。
- 開いた際は検索入力欄にフォーカスし、閉じた際はエディターに戻す。
- ノートブック内だけでの絞り込みや検索機能の追加は今回の対象に含めない。
- 仕様と実装の食い違いが判明した場合は、修正方針を確認する。

- [x] タグ名を検索し、クリックまたは Enter で選択できる。

## 実装・検証結果

- 検索 UI を独自実装に置換し、選択状態を React の状態で管理するように変更した。
- 多重選択の抑止は再描画で失われない参照で保持し、再表示時にリセットする。
- タグ取得、全ノート表示・検索解除・タグ絞り込みのコマンド順序は維持した。
- 日本語入力の変換中は Enter によるタグ選択を行わない。
- `.less` を `.css` に変更し、ダイアログ位置と配色を対応済み narrow シリーズに合わせた。
- ロックファイル内部のルートバージョンが `0.1.0` で、`package.json` の `0.4.8` と異なっていた。依存削除に伴うロックファイル再生成で `0.4.8` に同期された。
- 隣接 narrow-note のインストール済み Babel、React、jsdom、Testing Library を利用し、一時スクリプト `/private/tmp/narrow-tag-v6-check.cjs` で実コンポーネントを描画して検証した。新たな開発依存は追加していない。
- ローカル検証は全項目成功：大文字小文字を区別しない検索、日本語検索、上下移動と上下端、Ctrl-n / Ctrl-p / Ctrl-w、変換中の Enter、選択コマンドの順序とタグ ID、クリック、Escape、再表示時の検索リセットと最新タグ取得、候補なし、入力フォーカス、選択候補のスクロール呼び出し、購読解除。
- `npm install --package-lock-only --ignore-scripts --offline` が成功し、依存パッケージは不要になった。
- `npm pack --dry-run --ignore-scripts` が成功し、CSS と実装ファイルが配布対象に含まれることを確認した。
- `git diff --check` が成功した。
- 初回の実装時点では実機確認が未完了だった。続くユーザーの実機確認指示により、下記の確認を完了した。


## 実機確認結果

- 対象：macOS 上の Inkdrop 6.3.0。
- `ipm link` で本リポジトリをプラグインディレクトリにリンクし、デバッグ用ポート `9222` 付きで再起動した。
- 本リポジトリのプラグインが有効化され、`NarrowTagDialog` と `narrow-tag:open` が登録されていることを確認した。
- Chrome DevTools Protocol の入力イベントで以下を確認した。
  - 実データのタグ 18 個の表示、入力欄へのフォーカス。
  - 上下キーと Ctrl-n / Ctrl-p による候補移動。
  - 最終候補までのスクロールと、上下端での停止。
  - 大文字 `INK` による `inkdrop` の検索。
  - Ctrl-w による検索解除。
  - 候補なしでの Enter と上下移動で誤選択しないこと。
  - Escape による終了とエディターへのフォーカス復帰。
  - 再表示時の検索リセット。
  - Enter での選択後に検索条件が `tag:inkdrop` となること。
  - 実クリックでの選択後に検索条件が `tag:windows` となること。
  - 選択後にエディターへフォーカスが戻ること。
- `windows` の絞り込み結果 15 件すべてに該当タグが含まれることをストアの実データで確認した。
- 操作中の例外・未処理 Promise 拒否はなかった。
- 表示上の不一致を発見：候補一覧に指定した `--modal-background` は実機の v6 では未定義だった。`--dropdown-menu-background` に修正し、不透明な背景が適用されることを算出スタイルとスクリーンショットで再確認した。
- スクリーンショット：`/private/tmp/narrow-tag-v6-open.png`（初回表示）、`/private/tmp/narrow-tag-v6-search.png`（背景修正後の検索表示）。
- 実機テスト用スクリプト：`/private/tmp/narrow-tag-e2e.cjs`。開発依存の追加はない。
- 確認後は参照していたノート `note:8A61hl_h` を開き直し、デバッグ引数なしで通常起動した。修正版へのリンクは維持している。
- 今回の実機確認は 6.3.0 のみ。6.0～6.2 系と実際の日本語 IME 操作は未確認（変換中 Enter の抑止はローカル検証済み）。
