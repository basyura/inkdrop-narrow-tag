# ノートの絞り込み

## 確定処理

候補を `Enter` またはクリックで確定すると、そのタグの `_id` を使って Inkdrop のコマンドを実行する。

| 順序 | 直前の処理からの待ち時間 | 処理 |
| --- | --- | --- |
| 1 | なし | 多重選択を抑止するフラグを確認し、処理中なら終了する |
| 2 | なし | フラグを処理中にし、ダイアログを閉じて `editor:focus` を実行する |
| 3 | 100 ms | `core:note-list-show-all-notes` を実行する |
| 4 | 100 ms | `core:find-clear` を実行する |
| 5 | 100 ms | `core:filter-by-tag` に `{ tagId: 選択したタグの ID }` を渡し、その直後に `editor:focus` を実行する |

待ち時間は入れ子の `setTimeout` に指定した値。コマンドの完了を待って次の処理を行う仕組みではなく、実際の実行時刻はイベントループの状況に依存する。

既存の検索を解除して全ノートを対象にタグで絞り込む。現在のノートブックだけを対象に絞り込む機能はない。最終的な検索条件の解釈とノート一覧の更新は Inkdrop 本体が行う。

## 多重選択の抑止

`isClosingRef.current` により、同じ表示中に確定処理が重複して開始されることを防ぐ。この状態は再描画で失われず、次にダイアログを開く際に解除する。

## フォーカスとキャンセル

- ダイアログが非表示から表示に変わると、100 ms 後に入力欄が存在する場合はフォーカスする。
- 入力フォーカス用のタイマーは、表示状態の変更やアンマウントに伴う Effect のクリーンアップで解除する。
- 閉じる処理は `modal.close()` を呼んだ直後に `editor:focus` を実行する。
- `Escape` または背景クリックで閉じる場合、タグ絞り込みのコマンド列は開始しない。
- タグ確定時には、閉じる際と `core:filter-by-tag` の直後の 2 回、`editor:focus` を実行する。

## コマンドの送信先

共通の `invoke` 関数が `inkdrop.commands.dispatch` を呼ぶ。

- 要素の指定がない場合は `document.body` を送信先とする。
- パラメーターの指定がない場合は空オブジェクト `{}` を渡す。
- 現在の呼び出しはすべて `document.body` を送信先とする。
