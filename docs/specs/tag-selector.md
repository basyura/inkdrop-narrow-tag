# タグ選択

## ダイアログを開く

`narrow-tag:open` の実行時に、次の順で初期化する。

1. `.editor` の高さから[候補一覧の最大高さ](appearance.md#配置とサイズ)を設定する。
2. `inkdrop.store.getState().tags.all` からタグ一覧を取得する。
3. 検索文字列を空にし、選択位置を先頭の `0` に戻す。
4. 多重選択を抑止するフラグを解除する。
5. ダイアログを表示する。

タグの候補には、タグの `_id` を `key` と `value`、`name` を表示文字列 `text` として設定する。並び順は `tags.all` の順序を維持し、独自の並べ替えは行わない。

タグ一覧は開くたびに取得する。表示中の候補はその時点で取得した一覧を使い、ストアの変更を継続購読して更新する処理はない。

## 検索

- 入力欄のプレースホルダーと `aria-label` は `Select Tag`。
- 検索文字列とタグ名をそれぞれ `toLowerCase()` で小文字にし、タグ名に検索文字列が含まれる候補を表示する。
- 入力変更に応じて候補を更新し、選択位置を先頭に戻す。
- 空文字列では全候補を表示する。
- 前後の空白は除去しない。複数語への分割や正規表現への変換は行わず、入力全体を 1 個の文字列として検索する。
- 日本語のローマ字変換検索や Migemo 検索は行わない。

候補がない場合は `No tags found` を表示する。タグ一覧自体が空の場合も同じ表示になる。

## キーボード操作

以下は検索入力欄の `keydown` ハンドラーが処理する操作。

| キー | 動作 |
| --- | --- |
| `ArrowDown` / `Ctrl-n` | 次の候補へ移動する |
| `ArrowUp` / `Ctrl-p` | 前の候補へ移動する |
| `Enter` | 選択中の候補を確定する。候補がなければ確定しない |
| `Ctrl-w` | 入力全体を空にし、選択位置を先頭に戻す |
| `Escape` | 選択を確定せずに閉じる |

候補移動は先頭・末尾で止まり、循環しない。候補なしでも移動操作による選択の確定は起こらない。

上記のキーを処理する際は既定動作とイベントの伝播を抑止する。Ctrl 操作のキー判定は `ctrlKey` と小文字の `n`、`p`、`w` の一致による。

`nativeEvent.isComposing` が真の場合、このハンドラーは何も処理しない。日本語入力などの変換中に `Enter` がタグ選択として処理されることを避ける。

## マウス操作と終了

- 候補のクリックで、クリックしたタグを確定する。
- 候補の `mousedown` では既定動作を抑止し、クリック前に入力欄からフォーカスが移ることを防ぐ。
- マウスを重ねるだけでは選択位置を変更しない。
- 背景クリック時は `Dialog` の `onBackdropClick` を通じて閉じる。

タグ確定後の処理は[ノートの絞り込み](note-filtering.md)、フォーカスと選択候補の表示は[表示](appearance.md)を参照する。
